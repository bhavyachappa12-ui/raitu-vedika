# Raitu Vedika – Equipment Sharing Platform

## About the Project

Raitu Vedika is a community-based web platform that connects farmers who need agricultural equipment with equipment owners who are willing to rent out their machinery. The platform aims to make agricultural equipment more accessible, affordable, and easier to find.

It provides a digital space where farmers can search for equipment, send booking requests, and communicate with equipment owners.

## Key Features

- **User Registration and Login:** Separate access for farmers, equipment owners, and administrators.
- **Equipment Search:** Browse available agricultural machinery and view rental details.
- **Equipment Management:** Owners can add, update, and manage their equipment listings.
- **Booking Management:** Farmers can request equipment, and owners can accept or reject requests.
- **Dashboards:** Dedicated dashboards for farmers, equipment owners, and administrators.
- **Payment and Rental Process:** Supports the planned rental payment, equipment handover, and return workflow.
- **AI Assistant:** Helps users with platform-related queries.
- **Chat and Notifications:** Supports communication and booking updates.
- **Community Forum:** Encourages interaction within the farming community.
- **Additional Information:** Includes crop-weather updates, government scheme guidance, and crop recommendations.
- **Multilingual Support:** Telugu and English language options.

## User Roles

1. **Farmer:** Searches for agricultural equipment and manages booking requests.
2. **Equipment Owner:** Lists machinery, manages availability, and responds to booking requests.
3. **Admin:** Manages users, equipment listings, bookings, and platform activities.

## Technologies Used

- **Frontend:** React.js, Vite, HTML, CSS, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** Firebase / Cloud Firestore
- **Design:** Figma
- **AI Integration:** Gemini API
- **Version Control:** Git and GitHub

## Application Workflow

1. Users register and log in to the platform.
2. Farmers search and select the required equipment.
3. Farmers submit booking requests.
4. Equipment owners review and respond to requests.
5. The rental process continues through payment, equipment handover, and return.
6. Users can manage their activities through their respective dashboards.

## Project Objective

The main objective of Raitu Vedika is to reduce the difficulties farmers face in accessing agricultural machinery. It encourages equipment sharing, helps farmers avoid unnecessary machinery purchase costs, and provides equipment owners with an opportunity to earn rental income.
